Après l'installation

Ce qui reste à faire, une seule fois.

Si vous avez coché « Installer et régler la médiathèque », une fenêtre bleue fait le travail (quelques minutes, Windows demande l'autorisation). Attendez « Terminé » avant de suivre ce guide. Ce guide est aussi dans le dossier de l'appli : mediatheque\Guide.html

1. Votre indexeur dans Prowlarr (indispensable pour les films et séries en torrent)

  • Ouvrez http://localhost:9696 dans le navigateur.
  • Première ouverture : créez un identifiant et un mot de passe (Méthode : « Formulaire », Authentification : « Désactivée pour les adresses locales »).
  • Indexers > Add Indexer > cherchez votre tracker > remplissez vos identifiants ou votre clé (passkey) > Test > Save.
  • C'est tout : Prowlarr le transmet tout seul à Radarr et Sonarr (déjà reliés par l'installation), et le Lecteur IPTV trouve Prowlarr tout seul.

2. Le Lecteur IPTV en mode torrent

  • Paramètres > Lecture > « Films et séries : où lire » : Torrent (à la maison).
  • Paramètres > Sources : Prowlarr doit apparaître « relié » (sinon, relancez l'appli).

3. Jellyfin (votre bibliothèque de films et séries téléchargés)

  • Ouvrez http://localhost:8096 : l'assistant de première configuration s'ouvre.
  • Langue : Français. Créez votre compte.
  • Ajoutez deux bibliothèques :
    type Films > dossier C:\Mediatheque\Films
    type Séries > dossier C:\Mediatheque\Series
    Langue des métadonnées : Français, pays : France.
  • Pour pouvoir supprimer des titres depuis le lecteur : Tableau de bord > Utilisateurs > votre compte > cochez « Autoriser la suppression de médias ».
  • Dans le Lecteur IPTV : Films & séries > Ma médiathèque > connectez-vous (adresse http://localhost:8096, votre compte Jellyfin).

4. Radarr et Sonarr

  • Ouvrez http://localhost:7878 (Radarr) et http://localhost:8989 (Sonarr) une fois chacun pour créer leur identifiant (mêmes réglages que Prowlarr). Le reste est déjà réglé.
  • Vous avez déjà des films ou séries sur le PC ? Radarr : Films > Importer une bibliothèque ; Sonarr : Séries > Importer. Ils les reconnaissent et les rangent.

5. qBittorrent et le VPN (conseillé)

Pour que rien ne se télécharge quand le VPN est coupé :

  • qBittorrent > Outils > Options > Avancé > Interface réseau : choisissez la carte de votre VPN (pour CyberGhost : « CyberGhost Wintun Adapter ») > OK, puis fermez et rouvrez qBittorrent.
  • Le lecteur relance qBittorrent tout seul s'il reste bloqué après une reconnexion du VPN.
  • Interface web de qBittorrent : http://127.0.0.1:8085, identifiant admin, mot de passe dans C:\Mediatheque\qbittorrent-mdp.txt.

6. Chaînes IPTV avec le VPN actif

Si une chaîne est refusée quand le VPN est actif, le lecteur affiche les serveurs à exclure du VPN. Ajoutez-les dans les exceptions de sites de votre VPN (CyberGhost : Paramètres > Exceptions).

Plus tard

  • Mises à jour : Paramètres > Appareils > Médiathèque > « Installer / mettre à jour » vérifie et met à jour qBittorrent, Prowlarr, Radarr, Sonarr et Jellyfin.
  • Rangement : un film ou un épisode fini dans qBittorrent (catégorie films ou series) est rangé tout seul dans C:\Mediatheque, puis apparaît dans Jellyfin.
